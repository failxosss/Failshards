FailShards 5.0 - Professional Multi-Stage Effects Update

This update upgrades the visual system from simple orbiting displays to layered spell scenes.
Each ability can now render a staged composition using:
- buildup focus orb / cast phase
- rotating ground circle
- secondary sigil layer
- main emitters with per-motion paths
- accent burst / projectile / aura elements
- finish fade-out phase

Notes:
- Still uses ItemsAdder + ItemDisplay, no client mods required.
- Visuals are cosmetic only; damage / buffs remain in gameplay code.
- Exact bloom/shader glow from concept art is not possible in vanilla clients.
- Source was updated, but compilation and in-game behavior were not verified in this environment.
