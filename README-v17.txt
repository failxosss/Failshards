PvP heart loss: direct lethal damage attributed to another player (including player projectiles) removes one base heart, minimum one by default. No random percentages, no reward for killer. Environmental damage does not count. Health Shard bonus remains. Existing config may optionally add pvp-hearts.enabled and pvp-hearts.minimum-hearts; defaults true and 1. Build using existing GitHub Actions workflow. No resource pack updates required. Back up player data before installation.
